## 使用说明

**1. 查看课件**

点击上表中的 PDF 链接即可在线预览；如需下载，在预览页右上角选择下载，或用 Git 拉取整个仓库：

```bash
git clone https://github.com/dshi07188-ux/-.git
```

**2. 运行演示页面**

`*.html` 演示页下载后直接用浏览器打开即可交互，无需安装 Python / MATLAB 等环境，也不需要联网。

**3. 同步最新资料**

已进入本仓库目录时，随时执行：

```bash
git pull
```
